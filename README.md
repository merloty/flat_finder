# Flat Finder

Ежедневно ищет новые квартиры, фильтрует их и отправляет подборку в закрытый
Telegram-канал. Повторно уже отправленные объявления не публикуются.

## Что уже работает

- продажа квартир на Sreality, Bazoš, Maxi Reality Praha, RealityMix,
  Bezrealitky, Reality.iDNES и RE/MAX Czech;
- только `osobní vlastnictví`, исключение ателье, нежилых помещений, долей и
  кооперативной собственности;
- до 4,5 млн Kč и автомобильный маршрут до одной из въездных точек Праги не
  более 40 минут;
- отдельный поиск до 4 млн Kč в радиусе 5 км от центра Zábřeh;
- обход всех страниц выдачи до последней, включая отдельный поиск непосредственно по Zábřeh;
- ежедневный запуск GitHub Actions и ручной запуск из вкладки **Actions**;
- дедупликация через `state.json`.

Время автомобиля берётся без учёта текущих пробок. Железнодорожная доступность
и дополнительные источники будут добавлены следующими адаптерами; текущая
версия не выдаёт неподтверждённую информацию о поезде.

## Настройка Telegram

1. Создайте бота через `@BotFather` и сохраните токен.
2. Создайте закрытый канал, добавьте бота администратором с правом публикации.
3. В настройках репозитория откройте **Settings → Secrets and variables →
   Actions** и создайте secrets `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. `TELEGRAM_CHAT_ID` канала обычно выглядит как `-1001234567890`. Его можно
   получить, отправив сообщение в канал и открыв
   `https://api.telegram.org/bot<TOKEN>/getUpdates`.
5. Откройте **Actions → Daily flat search → Run workflow** для проверки.

Расписание находится в `.github/workflows/daily.yml`: `06:17 UTC`, то есть
08:17 летом или 07:17 зимой по времени Чехии.

## Ограничения

Порталы не предоставляют единый публичный API, поэтому при изменении конкретного
сайта его адаптер может потребовать обновления. Ошибка одного источника не
останавливает остальные. GitHub может запускать cron с небольшой задержкой.
Секреты никогда не добавляйте в файлы репозитория.
